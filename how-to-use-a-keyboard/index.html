Lección 3: Teclas Especiales

¿Qué son las Teclas Especiales?

Estas teclas no escriben letras ni números, pero son muy importantes para usar el teclado correctamente.

✏️ Teclas de escritura y formato

Estas teclas te ayudan a organizar lo que escribes, haciendo que el texto tenga forma y sentido.

␣

Tecla Espacio

Función

Separa palabras.

¿Cómo usarla?

Presiona una vez para dejar un espacio.

Tip

Cada pulsación inserta un espacio; mantenerla pulsada crea varios espacios.

Ejemplo

Holaamigo → Hola amigo
La tecla espacio nos permite separar "Hola" de "amigo".

↵

Tecla Enter

Función

Salta de línea o confirma una acción.

¿Cómo usarla?

Presiona para crear nueva línea o enviar formularios.

Tip

En textos, crea un nuevo párrafo; en formularios, envía la información.

Ejemplo

Al terminar de escribir un párrafo, presiona Enter para comenzar uno nuevo.

⇥

Tecla Tabulador

Función

Mueve el cursor a la siguiente posición/tabulación.

¿Cómo usarla?

Presiona para mover el cursor al siguiente campo o crear sangría.

Tip

En formularios, salta entre campos; en textos, crea sangrías profesionales.

Ejemplo

En un formulario web, presiona Tab para pasar del campo "Nombre" al "Apellido".

⇪

Tecla Bloq Mayús

Función

Cambia a mayúsculas permanentes.

¿Cómo usarla?

Presiona una vez para activar, presiona nuevamente para desactivar.

Tip

Ideal para escribir muchas mayúsculas seguidas; una luz en el teclado indica si está activo.

Ejemplo

Para escribir "CHILE" en mayúsculas: presiona Bloq Máyus, escribe CHILE, presiona otra vez BBloq Máyus para desactivar.

🔑 Teclas de modificación

Estas teclas son como "ayudantes": trabajan en equipo con otras teclas para hacer cosas diferentes.

Ctrl

Tecla Control

Función

Permite atajos (Ctrl + C para copiar, Ctrl + V para pegar, etc.).

¿Cómo usarla?

Mantén presionada mientras pulsas otra tecla.

Tip

Combinada con otras teclas realiza acciones rápidas.

Ejemplo

Para copiar texto: selecciona el texto y presiona Ctrl + C; para pegarlo: Ctrl + V.

⇧

Tecla Shift

Función

Cambia el carácter (mayúsculas, símbolos).

¿Cómo usarla?

Mantén presionada mientras pulsas otra tecla.

Tip

Usa Shift + letra para mayúsculas; Shift + número para símbolos (!, @, #, etc.).

Ejemplo

Para escribir "Hola" con H mayúscula: mantén Shift + presiona H, luego suelta y escribe "ola".

Alt Gr

Tecla Alternativa Gráfica

Función

Escribe caracteres especiales (como @ o #).

¿Cómo usarla?

Mantén presionada mientras pulsas teclas con terceros símbolos.

Tip

Esencial para escribir arroba (@), almohadilla (#), euro (€) y otros símbolos especiales.

Ejemplo

Para escribir arroba (@) en muchos teclados: mantén Alt Gr + presiona la tecla Q o 2.

✂️ Teclas de edición

Estas teclas son las que usamos cuando queremos corregir o quitar algo.

⌫

Tecla Retroceso

Función

Elimina texto o elementos.

¿Cómo usarla?

Presiona para borrar caracteres antes del cursor.

Tip

Mantenerla pulsada borra texto rápidamente.

Ejemplo

Si escribes Autoo por error, usa Borrar para borrar la "o" extra.

🪟 Teclas del sistema o acceso rápido

Estas teclas no sirven para escribir, pero ayudan a moverte por el computador y acceder a funciones especiales.

⊞

Tecla Windows

Función

Abre el menú inicio y permite accesos rápidos.

¿Cómo usarla?

Presiona sola para abrir el menú Inicio; combínala con otras teclas.

Tip

Windows + E abre el Explorador; Windows + D muestra el escritorio.

Ejemplo

Para buscar un programa rápidamente: presiona Windows y escribe el nombre del programa.

Ejercicios Prácticos

Ejercicio 1: Agrega espacios entre las palabras

A continuación verás una frase sin espacios. Tu tarea es reescribirla correctamente agregando espacios donde corresponda.

Ejemplo:
Texto original: elcieloeslindo
Respuesta correcta: el cielo es lindo

💡 Recuerda: Para escribir, primero haz clic en el cuadro blanco

Texto a separar: lamanzanaesdulce

Ejercicio 2: Crea una lista de compras

Escribe una lista de 3 elementos, presionando Enter después de cada uno para pasar a la siguiente línea.

Ejemplo:
🛒 pan [ENTER]
🛒 leche [ENTER]
🛒 arroz

💡 Usa Enter para escribir cada elemento en una nueva línea

Ejercicio 3: Corrige errores con la tecla Borrar

El siguiente texto tiene algunos errores. Tu tarea es corregirlo usando la tecla Borrar (⌫).

Importante: Para borrar una letra debes hacer clic justo al lado derecho de la letra que quieras eliminar. Luego presiona la tecla Borrar para quitarla.

✏️ Texto con errores:
"El perroo es un animal domesttico muy fiel"

✅ Texto corregido:
"El perro es un animal domestico muy fiel"

💡 Haz clic al final o al lado de la letra incorrecta antes de presionar Borrar

Ejercicio 4: Escribe en mayúsculas

Escribe la siguiente frase usando solo mayúsculas. Puedes usar la tecla Bloq Mayús o mantener presionado Shift mientras escribes.

Frase: el teclado tiene muchas teclas

💡 Consejo: Bloq Mayús deja todo en mayúsculas hasta que lo presiones otra vez

Ejercicio 5: Usa Shift para escribir símbolos

Escribe los siguientes símbolos usando Shift y la tecla de número correspondiente.

Símbolos a escribir: # $ %

💡 Mantén presionado Shift y presiona el número que tiene el símbolo. Ej: Shift + 3 → #

Ejercicio 6: Escribe tu correo con @

Escribe tu correo electrónico. Recuerda que el símbolo @ se escribe manteniendo presionado Alt Gr o Shift (dependiendo del teclado) y presionando la tecla correspondiente.

Ejemplo: juan@example.com

💡 Usa Alt Gr + Q o Shift + 2 (según tu teclado) para escribir @

Ejercicio 7: Navega entre campos con Tab

Completa el formulario usando la tecla Tab para pasar de un campo al siguiente.

Instrucciones:
Escribe en el primer campo, presiona Tab para ir al segundo, y así sucesivamente.

💡 Usa Tab para moverte entre campos sin usar el mouse
